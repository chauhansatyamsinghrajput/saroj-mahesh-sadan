# सरोज महेश सदन – Griha Pravesh Invitation

Static site: `index.html`, `style.css`, `script.js`. No build step, no external requests.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

## Deploy (free, HTTPS)
- **Netlify:** go to app.netlify.com/drop and drag this folder in. You get a public https link.
- **GitHub Pages:** create a repo, upload these files, then Settings → Pages → Deploy from branch → `main` / root.

## Share on WhatsApp
Copy the public https link and paste it into WhatsApp. Or open the link on a phone and tap "शेयर करें".

## Notes
- Ganesha, house and ornaments are inline SVG drawings (no image files; `assets/` is empty and optional). Replace the SVG with your own artwork/photo if you want a more detailed look.
- Music was omitted (it would need an audio file you own).
- Fonts use system Hindi fonts (Noto Serif Devanagari, Nirmala UI, Mangal, etc.).
